============
Installation
============

Since pip no longer offers the PyQt version required by qmxgraph you will need `pixi`_ to setup the environment.
Until a new version is published the only option is getting the source code.
To install the required dependencies and build the necessary static resources:

.. code-block:: shell

    git clone https://github.com/ESSS/qmxgraph.git
    cd qmxgraph
    git clone --depth=1 --branch v3.7.5 https://github.com/jgraph/mxgraph.git
    pixi run inv qrc

If you want to run the tests, which need Google Chrome installed:

.. code-block:: shell

    pixi run inv test

To build this documentation locally:

.. code-block:: shell

    pixi run inv docs

The environment is generated by `pixi-devenv`_: edit ``pixi.devenv.toml`` instead of
``pixi.toml``, then run ``pixi exec pixi-devenv update``.

.. _pixi: https://pixi.sh
.. _pixi-devenv: https://github.com/ESSS/pixi-devenv
